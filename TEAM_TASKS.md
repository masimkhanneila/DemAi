## Prerequisite: leader's shared foundation

Member 2 (team leader) prepares and merges `feature/assignment6-foundation` **before** members 1 and 3 start their feature branches. It contains:

- `database.py` with `engine`, `SessionLocal`, `Base`, `get_db()`
- `.env.example`, `.gitignore`, up-to-date dependencies
- `models/` package and Alembic configuration
- A verified local connection to PostgreSQL

**Important:** The complete initial migration should be generated **only after all three model definitions have been merged**. Each member creates ORM models, but the leader owns and commits the final migration. Do not upload `.env`.

## Shared decisions (all three follow these)

1. SQLAlchemy ORM 2.x + synchronous Psycopg 3, standard `Session`, shared `Base` and `get_db`.
2. Table names: `stations`, `routes`, `saved_routes`.
3. PK: integer `id` generated by PostgreSQL.
4. FK: `routes.station_id → stations.id`; `saved_routes.route_id → routes.id`, restrictive deletes (not cascade).
5. Relationships: `Station.routes` ↔ `Route.station`, `Route.saved_routes` ↔ `SavedRoute.route`.
6. Unique key for `saved_routes`: `(user_id, route_id)`.
7. No Users table, authentication, external pollution API, or new endpoint paths.
8. Status codes: success 200/201/204; missing 404; conflict 409; invalid 422.
9. Preserve existing Pydantic schemas/validation and computed response fields, adjusting only as necessary for ORM output.
10. Teammates make PRs to `main`, not direct pushes to `main`.
